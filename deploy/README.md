# Как запустить бота — три способа

Токен берётся у [@BotFather](https://t.me/BotFather): если старый где-то засветился —
`/revoke` → выбрать бота → скопировать новый. Токен живёт только в `.env`
(или в переменных окружения хостинга), в git он не попадает.

---

## Вариант 1. Mac, два клика (быстро проверить)

1. `@BotFather` → `/revoke` → скопировать токен.
2. Finder → `projects/schedule-bot` → двойной щелчок **«Запустить бота.command»**.
   Если macOS скажет «неизвестный разработчик»: правый клик по файлу → **Открыть** → **Открыть**.
3. В диалоге вставить токен → **Сохранить**.
   Скрипт сам создаст `.venv`, поставит зависимости, проверит токен и запустит бота.
4. В Telegram: `/start` → `/id` → записать число.
   Закрыть бота (Ctrl+C), открыть `.env` двойным щелчком (TextEdit), вписать `ADMIN_IDS=число`,
   снова запустить `.command`.
5. `/admin` → **Загрузить PDF** → проверить предпросмотр → **Опубликовать**.

Работает, пока Mac включён и окно терминала открыто. 0 ₽.

## Вариант 2. VPS, ~10 минут, работает 24/7 (для постоянной работы)

Нужен любой VPS с Ubuntu 24.04 (1 ГБ памяти хватает): Timeweb, Aeza, Beget, NetAngels —
150–300 ₽/мес. Всё делается с телефона.

### Что именно покупать

| Параметр | Значение | Почему |
|---|---|---|
| Тип | **облачный сервер / VPS**, не «хостинг сайтов» | нужен root и свой процесс |
| Локация | **Амстердам, Франкфурт, Варшава, Алматы** | из РФ-дата-центров `api.telegram.org` периодически троттлится |
| Конфиг | 1 vCPU, **1 ГБ RAM**, 10–15 ГБ NVMe | бот занимает ~70 МБ, запас есть |
| ОС | **Ubuntu 24.04 LTS**, чистая | под неё написан установщик |
| Панель | **без панели** (никакого ISPmanager/cPanel) | панель съедает 300–500 МБ и не нужна |
| Цена | 200–400 ₽/мес | оплата российской картой |

Провайдеры, где есть зарубежные локации и оплата картой РФ: **Timeweb Cloud** (Амстердам),
**Aeza** (Франкфурт/Амстердам), **RUVDS** (Амстердам), **Beget** (СПб — дешевле, но ближе
к риску с Telegram).

1. Купить VPS, в панели хостинга открыть **«Консоль»** (браузерный терминал).
   Логин `root`, пароль — из письма (при вводе не отображается).
2. Вставить одну строку и нажать Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/mospoliteh2627-alt/schedule-bot-medcollege/main/deploy/install-vps.sh | sudo bash
```

3. Скрипт спросит **токен** (ввод не отображается — это нормально) и **Telegram id**
   (можно оставить пустым). Дальше всё сам: Python, код, служба systemd.
4. В Telegram: `/start` → `/id` → вписать id и перезапустить:

```bash
sudo nano /opt/schedule-bot/.env      # строка ADMIN_IDS=ваш_id
sudo systemctl restart schedule-bot
```

5. `/admin` → **Загрузить PDF** → **Опубликовать**.

Полезное:

```bash
journalctl -u schedule-bot -f                                  # логи
systemctl restart schedule-bot                                 # перезапуск
cd /opt/schedule-bot && sudo git pull && sudo systemctl restart schedule-bot   # обновление
```

## Вариант 3. Render (бесплатно, но с оговоркой)

Подходит, чтобы показать бота, а не работать с ним месяцами: на free-тарифе контейнер
эфемерный — файл `data/schedule.sqlite3` обнуляется при перезапуске, а без трафика сервис
засыпает. Для постоянной работы нужен диск (≈$0.25/ГБ) или VPS из варианта 2.

1. Репозиторий уже есть: `github.com/mospoliteh2627-alt/schedule-bot-medcollege`.
2. С телефона открыть [render.com](https://render.com) → **Sign in with GitHub** → разрешить доступ.
3. **New +** → **Blueprint** → выбрать `schedule-bot-medcollege` → **Apply**.
4. В поле `BOT_TOKEN` вставить токен, в `ADMIN_IDS` — свой id (если уже знаете) → **Deploy**.
5. Через 2–3 минуты статус **Live**. Проверка: `https://<имя>.onrender.com/healthz` → `ok`.
6. Чтобы сервис не засыпал: [cron-job.org](https://cron-job.org) → новая задача на тот же
   `/healthz` каждые 10 минут (бесплатно).

## Если что-то не так

| Симптом | Причина | Что делать |
|---|---|---|
| `Conflict: terminated by other getUpdates` | запущены два экземпляра | закрыть лишний терминал / `systemctl stop schedule-bot` |
| `Telegram не принял токен` | токен отозван или опечатка | `/revoke` у BotFather, новый токен в `.env` |
| Бот молчит на `/admin` | ваш id не в `ADMIN_IDS` | `/id` → вписать → перезапустить |
| «Не найдено ни одного занятия» | PDF-скан без текстового слоя | нужен PDF из учебной части, не фото |
| Расписание пропало после перезапуска облака | эфемерный диск (Render free) | VPS или платный диск |

## FAQ

**Можно ли «залить бота в Telegram», чтобы он там крутился?**
Нет. Telegram — это мессенджер и Bot API, он не запускает чужой код. Загрузить можно только
токен, имя, аватар и описание бота. Сам код (Python-процесс) должен работать на машине:
VPS, домашний Mac, старый ноутбук, Raspberry Pi или облако. Telegram лишь передаёт сообщения.

**А мини-приложение (Web App) внутри Telegram?**
Кнопка меню может открыть ваш сайт прямо в Telegram, но файлы сайта всё равно лежат
на HTTPS-хостинге. Telegram — окно, а не сервер.

**Что тогда «крутится в Telegram»?**
Всё управление: загрузка PDF, предпросмотр, публикация, рассылка изменений, статистика,
кнопки у студентов. Ни разу не нужно открывать сайт или компьютер — только чат с ботом.
Единственное, что живёт вне Telegram, — сам процесс бота (и файл базы `data/schedule.sqlite3`).
